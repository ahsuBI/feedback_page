Luma feedback chatbot

A short feedback conversation for a fictional cosmetics brand. Pick a topic, tap through a few questions, and finish to unlock the spin wheel.

The original was built in IBM Watson Assistant for a course project. The Watson trial behind it has expired, so this version recreates the same conversation flow in plain HTML and JavaScript to keep it playable.
